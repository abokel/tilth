# Wheat Leaf Rust

**Wheat Leaf Rust** (_Puccinia triticina_), fungus.

- **Hosts:** common wheat, durum wheat.
- **Spreads:** airborne spores.
- **Favoured by** 10-30 °C (best 20 °C), humidity above 80%, 3 h of wet leaves.

- **Survives** 0.3 years (volunteer wheat).
- **Damage:** up to 40% yield.
- **Control:** Resistant cultivars (Lr genes); Destroy volunteer wheat; Fungicide.
