# Root-knot Nematode

**Root-knot Nematode** (_Meloidogyne spp._), nematode.

- **Hosts:** tomato, carrot, potato, lettuce, peanut, soybean, cotton.
- **Spreads:** soilborne.
- **Favoured by** 20-33 °C (best 28 °C).

- **Survives** 3 years (soil).
- **Damage:** up to 40% yield.
- **Control:** Rotation with grasses; Solarisation; Resistant varieties (Mi gene in tomato).

Thrives in warm, sandy soils.
