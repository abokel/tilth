# Managing Plots

**/tilth plot list** shows every plot. **here** and **info <name>** describe one, **rename** and **delete** manage them, and **addmember** / **removemember** share them.

Plot protection (only owners and members may build or harvest inside) is available but off by default: set plots.protection in the config.
