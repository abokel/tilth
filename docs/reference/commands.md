# Commands

**Look things up:**
- /tilth calendar
- /tilth climate
- /tilth soil
- /tilth catena
- /tilth water
- /tilth crop
- /tilth diet
- /tilth plot ...
- /tilth affliction ...

Most act on the block you look at.

**Debugging** (operators):
- /tilth time skip <days>
- /tilth time set <month> <day>
- /tilth soil set <property> <value>
- /tilth soil amend <type>
- /tilth crop setstage|grow|kill
- /tilth fillfield <crop> <radius>
- /tilth debug hud
